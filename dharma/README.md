# 🕉️ DHARMA BOOKS PRO — Sacred Scriptures & Publishing House

**Dharma Books Pro** is an enterprise-grade, high-performance, production-ready Religious Scripture Publishing & E-Commerce platform for Vedic texts, Bhagavad Gita, Upanishads, Ramayana, Puranas, Stotras, and devotional literature.

---

## ✨ Features Overview

- 📚 **Authentic Catalog**: Hardbound physical scriptures, high-res watermarked PDFs, and audio QR integrations.
- 🎨 **Enterprise Themes**: High-contrast Light Mode (Saffron & Gold accents) and Emerald Dark Mode.
- ⚡ **Lightning Fast UI**: Built with React 18, Vite, Tailwind CSS, Lucide Icons, and Motion transitions.
- 🛡️ **Cyber Hardened**: Anti-XSS input sanitization, Sliding Window rate limiting, Anti-Bot honeypot traps, strict CSP & Security HTTP headers.
- 💳 **Checkout & Logistics**: Razorpay, UPI QR, COD, India Post, Delhivery, DTDC, and Blue Dart shipping calculators.
- 🏢 **Executive Control Suite**: Sales analytics, book CRUD, stock warning triggers, order status update, and Supabase SQL migration exporter.

---

## 🚀 Quick Start & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```

### 3. Build Production Bundle
```bash
npm run build
```
